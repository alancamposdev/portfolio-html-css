# portfolio-html-css

Portfólio semântico e responsivo.

## 🚀 Demo

[Acessar o porfólio - github-pages](https://alancamposdev.github.io/portfolio-html-css)

## 🛠 Tecnologias

- HTML5 semântico
- CSS3 — Custom Properties, Flexbox, CSS Grid
- JavaScript vanilla (ES6+)
- Google Fonts (Syne, DM Sans, JetBrains Mono)
